## Design Context

This project uses the `/impeccable` skill. Read `PRODUCT.md` (register: product — who/what/why) and `DESIGN.md` (visual system: colors, typography, components) before any UI work. Key rules: zero border-radius anywhere, glow-only elevation (never a drop-shadow), one accent color per mini-game via `src/lib/gameTheme.ts`, modals close only via an explicit X/[ CLOSE ] control, no strobe/seizure-risk motion.
